# Contributing

1. Create changes from `develop`.
2. Keep pull requests focused and include tests for behavior changes.
3. Run `npm test` before submitting.
4. Do not commit application data, credentials, family information, build artifacts, or signing keys.
5. Report security issues privately as described in `SECURITY.md`.

User-facing text should remain clear in Traditional Chinese. Features should support family collaboration by default; parental restrictions apply only to explicitly managed devices.
