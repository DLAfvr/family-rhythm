# 家庭節奏 Family Rhythm

家庭提醒、責任表與 Windows 使用時間管理工具。它不只為孩子設計，也能用於家人之間的喝水、休息、吃藥與生活協作。

> 目前為 Windows 10／11 桌面版。家庭同步只在同一個私人區域網路內運作，不依賴自建伺服器。

**作者／主要維護者：沈晏**

## 功能

- 固定時刻、開始使用後、中間、任務與關機提醒
- 每個提醒可選顏色、內建音效或自訂 MP3／WAV／OGG／M4A
- 每日、平日、假日、自訂星期與單次責任任務
- 可跨日累積的「時間晶幣」，用於提早開始或延長使用
- 家長可限制最早使用時間與晚間最多延長分鐘
- 桌面小工具、系統匣常駐、開機自動啟動
- 家庭內網配對、提醒／責任表同步及多位家長管理
- 家長鎖可憑目前密碼移除；受管理裝置移除時會通知家庭管理者並留下紀錄
- 平日／假日可使用不同額度與固定關機時間
- 可建立多個寒暑假或特殊假期日期區間，優先套用各自的每日額度與關機時間
- 本機通知中心、受管理裝置離線／恢復連線警示
- 備份與還原提醒、責任表、音效、時間規則及晶幣（不匯出密碼或配對權杖）
- 家長可要求受管理裝置恢復家長鎖，密碼只在該裝置本機設定
- HELP 顯示版本，支援 GitHub Releases、家庭裝置版本檢查與確認式一鍵更新

## 安裝

請從 [Releases](https://github.com/DLAfvr/family-rhythm/releases) 下載最新安裝版。第一次測試請保持「安全測試模式」開啟；確認倒數符合預期後，再允許實際關機。

作為主要電腦時，Windows 防火牆只應允許「私人網路」，不要開放公用網路。建議使用安裝版，讓防火牆規則對應固定路徑。

## 開發

```powershell
npm install
npm test
npm start
```

建立 Windows 安裝版與免安裝版：

```powershell
npm run pack
```

## 分支

- `main`：穩定、可發布版本
- `develop`：下一版整合
- 功能與修正從 `develop` 建立短期分支

## 安全邊界

家庭節奏適合可信任的家庭私人網路，但不是企業級端點管理或不可繞過的 Windows 系統服務。具備 Windows 管理員權限的人仍可能停止程式或刪除本機資料。

- 家長管理操作需密碼解鎖，五分鐘後自動鎖定。
- 配對碼十分鐘過期，同一來源錯誤五次後暫停嘗試。
- 配對成功後以高熵權杖驗證同步請求。
- 目前內網傳輸未使用 TLS；請勿在公共 Wi-Fi 使用。
- 更新來源固定為官方倉庫；安裝檔會核對 GitHub SHA-256，且必須由已解鎖的家長確認才會執行。

安全問題請依照 [SECURITY.md](SECURITY.md) 私下回報，不要先建立公開 Issue。
